# Карточки блюд MOJO — редактор в Академии

Маршрут в Telegram Mini App: **Курсы → Карточки блюд · управление** (для `manager` / `local`).
Для официантов/стажёров: **Курсы → Карточки блюд** — только опубликованные позиции.

## Возможности

- Администратор загружает PDF станционок (до 20 000 000 байт) напрямую в закрытый API Академии.
- PyMuPDF извлекает встроенные фотографии, текстовые названия, ингредиенты, фрагменты описаний и номера страниц. **Без обращения к стороннему ИИ.**
- Всё импортируется **черновиками** в PostgreSQL; фото хранятся в `BYTEA`, не публикуются в GitHub или общедоступном каталоге.
- Менеджер видит замечания, меняет название, ингредиенты, описание, фотографию, архивирует устаревшую позицию и вручную подтверждает публикацию.
- После редактирования опубликованного блюда оно снова становится черновиком.
- Одинаковый PDF не дублируется при повторном импорте благодаря `source_hash + page + slot`.
- Сотрудники видят только опубликованные карточки; вход и права проверяются существующей Telegram-сессией.
- Курсы и тесты не меняются; карточки — отдельная база знаний.

## Ограничения распознавания

PDF MOJO не всегда имеет однозначное соответствие фото и рецепта. Особенно тщательно проверять страницы с двумя блюдами и фото, изменения рецептов, аллергены, неполные описания. **Импорт никогда не публикует всё автоматически.** Для PDF без текстового слоя может потребоваться ручное заполнение.

## Безопасный выпуск на Selectel

1. Дождаться зелёного CI для PR, согласовать/влить ветку в `main`.
2. В SSH на Selectel: `cd /opt/service`, затем `git status --short`. При незнакомых изменениях — остановиться.
3. Создать резервную копию: `sudo bash pilot/backup.sh`.
4. Обновить только Академию: `git pull --ff-only origin main`, затем `sudo bash pilot/update-pilot-only.sh`.
5. Чтобы разрешить PDF и загрузку фото через Caddy: `sudo bash pilot/enable-dish-upload.sh`. Скрипт делает резервную копию конфигурации, проверяет её и откатывает при ошибке. **Не запускать `deploy-pilot.sh`**, он может перезаписать прокси других приложений.
6. Открыть Telegram → Академия → Курсы → Карточки блюд · управление. Загрузить PDF и убедиться, что позиции появились черновиками.
7. Проверить минимум три разные карточки, их фотографии, ингредиенты и номера страниц. Исправить ошибки, только затем публиковать.
8. На учётной записи официанта убедиться, что черновики скрыты, опубликованная карточка видна, а после правки менеджером снова скрыта.
9. После перезапуска API проверить сохранность карточек в PostgreSQL.

### Тесты

В папке `pilot` после `pip install -r requirements.txt`:

```bash
python -m unittest test_dishes test_cases test_pilot
node --check dishes.js
```

CI запускает тесты на отдельной тестовой PostgreSQL. Это не заменяет проверку на настоящем Selectel и телефоне.

### Важное разделение

Этот PR интегрирует **редактор карточек в кабинет менеджера Академии**. Он не загружает конфиденциальный PDF в GitHub, не импортирует его в рабочую базу без явного действия менеджера, не обновляет учебные курсы автоматически и не требует Yandex AI ключа.
