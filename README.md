# Академия сервиса

Демонстрационный Telegram Mini App для **@skill_mojo_bot**, ресторан MOJO.

## Что работает

- Кабинеты стажёра, официанта, менеджера по сервису и менеджера точки.
- Четыре учебных модуля, тест из пяти вопросов, результат и прогресс.
- Редактор вопросов/вариантов/правильного ответа у менеджера по сервису.
- Создание тренинга с датой, временем, ведущим, вместимостью и минимумом участников.
- Запись/отмена, ограничение по местам, просмотр числа участников.
- Назначение переаттестации → отображение в кабинете официанта.
- Даты и очные результаты сдачи меню/виртуального стола; перевод в официанты после обоих экзаменов.
- Демонстрационная регистрация, ссылка и QR приглашения в MOJO.
- Сохранение на одном устройстве через localStorage, сброс для нового показа.

Это интерактивное демо, не production LMS. Все роли доступны переключателем, серверной авторизации нет; записи между устройствами не синхронизируются. Телефон вводится вручную как учебный пример и не проверяется. Реальные данные сотрудников не вводить. Прямые уведомления Telegram и Yandex API не подключены. Пользовательские поля экранируются при отображении.

## Запуск

Статические index.html, app.js, style.css, invite.svg. Сборка и npm не нужны.

```bash
python3 -m http.server 8080
node test.cjs
```

Деплой Selectel и BotFather: [DEPLOY.md](DEPLOY.md). Следующий этап: [ROADMAP.md](ROADMAP.md).

## Сценарий встречи (3–5 минут)

1. Стажёр → «Продолжить обучение» → урок → тест. Правильные ответы: 1, 2, 3, 1, 2.
2. Менеджер по сервису → События → создать тренинг.
3. Официант → События → записаться. Менеджер → Участники: новая запись видна.
4. Менеджер → Команда → карточка Александра → изменить даты → отметить очные экзамены → сохранить → перевести в официанты.
5. Менеджер → назначить переаттестацию. Официант → Мой путь: назначение появилось.
6. Пригласить сотрудника → QR и «Показать вход».
7. Профиль → Сбросить демо для следующего показа.

Даты исходного набора привязаны к демонстрации 20 октября 2026. Меняются менеджером. Прогресс состоит из четырёх модулей и двух очных экзаменов; это не срок стажировки и не автоматический допуск.
